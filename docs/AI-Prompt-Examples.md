You can use an AI coding assistant (for example Claude Code, OpenAI Codex or another assistant) to
build, debug or extend PocketFin. Paste one of these prompts into the assistant while it is working in
your copy of this repository. Check what it does; you are responsible for what ends up on your card.

## Safety rules to include

Add this block to any prompt (or to the assistant's project instructions file):

```text
Rules for this repository:
- Work on the PC only. Do not write to an SD card, a Pocket, a Chromatic or any device unless I say so
  in this conversation, and never change console firmware.
- Never read, print or copy private/ (my Jellyfin sign-in) or anything with Wi-Fi names, passwords,
  tokens or server addresses. Do not put secrets on command lines or in logs.
- Never edit release/SD/Cores/ChaoticSPARTAN1.Jellyfin/interact.json. Other versions hung the Pocket.
- Keep the attribution "ChaoticSPARTAN1" in credits and the About screen (ADDITIONAL-TERMS.md).
- Do not add third-party videos, images or code unless their licence allows it; say which licence.
- Run the tests in docs/Building-from-Source.md after changes and tell me which passed or failed.
- Do not push, publish or create repositories unless I ask.
```

## Building

```text
Read docs/Building-from-Source.md. Fetch the upstream sources, build the app with
tools/Build-LivePlayer.ps1 and tell me whether pjlive.elf matches the SHA-256 in release/SHA256SUMS.txt.
If a tool is missing, tell me exactly what to install and where; do not install anything without asking.
```

```text
Prepare the FPGA core tree with tools/prepare_pocket_media_core.py and run a Quartus map (no fit) with
tools/Build-PocketMediaCore.ps1. Summarise errors and warnings that concern files under rtl/.
```

## Troubleshooting

```text
My Pocket shows a black screen with a flashing backlight when I start the Jellyfin core. I already
switched it off fully. Here is the list of files in Cores/ChaoticSPARTAN1.Jellyfin on my card with their
SHA-256 values: <paste>. Compare them with release/SHA256SUMS.txt and tell me which files to restore.
Do not suggest editing interact.json.
```

```text
tools/make_offline_library.py fails with this message: <paste, with any paths or names removed>.
Find the cause in the code and suggest a fix. Test it with a video generated by FFmpeg
(testsrc2 + sine), not with my own files.
```

## Adding features

```text
I want subtitles for videos on the SD card. Read pocket/sd_library.h, tools/pocket_library.py and
tools/live_av.py. Propose a design that keeps the existing library format readable (version it), list
the files to change, then implement it with a PC test in pocket/check_sd_library.c. Keep frame timing
and audio unchanged. Do not touch the FPGA core.
```

```text
Add a Settings screen to the app for buffer length and volume, using the existing values in
pocket/core_settings.h. Draw it in the same style as live_ui.h. Add a case to
pocket/check_live_controller.c and render a preview with tools/test_native_client.py. Show me the
preview image.
```

## Reviewing a change

```text
Review my uncommitted changes for bugs. Focus on buffer sizes, integer overflow, timing on the
Pocket's 90 MHz CPU and anything that could stop saves being written at quit. Run the tests and report
results. Do not make changes; list findings with file and line.
```
