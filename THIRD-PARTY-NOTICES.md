## Components

**openfpgaOS SDK** - https://github.com/openfpgaOS/openfpgaSDK (commit a408ddc).
Copyright (c) 2026 ThinkElastic. Apache-2.0 ([Apache-2.0.txt](LICENSES/Apache-2.0.txt)); its NOTICE
file is [openfpgaSDK-NOTICE.txt](LICENSES/openfpgaSDK-NOTICE.txt). musl libc inside it: see below.
The SDK also contains a SoundFont and tracker modules of unclear provenance (its
`LicenseRef-Proprietary-SampleData` and `LicenseRef-ThirdParty-Media`); PocketFin does **not** use
or ship any of them.

**openfpgaCore** - https://github.com/openfpgaOS/openfpgaCore (commit 618a3eb). Copyright (c)
2026 ThinkElastic. Apache-2.0 for its own files ([Apache-2.0.txt](LICENSES/Apache-2.0.txt)); its
NOTICE file is [openfpgaCore-NOTICE.txt](LICENSES/openfpgaCore-NOTICE.txt). PocketFin does not
include this source; it is fetched by `tools/fetch_upstreams.py` and patched by
`tools/prepare_pocket_media_core.py`.

PocketFin's changes to openfpgaCore's Apache-2.0 files (the patch hunks applied to
`src/firmware/os/hal/link.c`, `src/firmware/os/hal/net.c`, `src/firmware/os/hal/regs.h` and
`src/fpga/common/axi_periph_slave.v` by `tools/prepare_pocket_media_core.py`) are contributed under
the Apache License, Version 2.0, so those patched files, and the kernel and boot ROM built from
them, stay under Apache-2.0. The rest of that script is GPL-3.0-or-later like the rest of PocketFin.

The bitstream built from openfpgaCore also contains:
- the **Analogue Pocket Framework** (`apf/`, `core_top.v`, `core_bridge_cmd.v`, `io_sdram.v`),
  Copyright (c) Analogue Enterprises Limited, under the Analogue Pocket Framework Software
  License Agreement ([LicenseRef-Analogue-Pocket-Framework.txt](LICENSES/LicenseRef-Analogue-Pocket-Framework.txt)).
  That agreement says that where the GPL applies and its terms are inconsistent with the agreement,
  the GPL prevails. PocketFin changes `core_bridge_cmd.v` (save-on-exit fix) and `core_top.v`
  (link block) by script; the changes are in `tools/pocket_save_exit_patch.py` and
  `tools/prepare_pocket_media_core.py`.
- **Intel/Altera megafunction IP** generated by Quartus (PLLs, block RAM, DDIO) and Quartus library
  modules, Copyright (c) Intel Corporation, under the licence in
  [LicenseRef-Intel-FPGA-IP.txt](LICENSES/LicenseRef-Intel-FPGA-IP.txt): it may be used to program

Pocket Framework and the Intel/Altera IP ([ADDITIONAL-TERMS.md](ADDITIONAL-TERMS.md)).
The Analogizer and other third-party video files in openfpgaCore are **not** part of this build
(Quartus' list of source files read for the released bitstream does not include them).

## Build tools (not shipped)

Intel Quartus Prime Lite, the RISC-V GCC toolchain, MSYS2, Icarus Verilog, Python, fontTools, PyAV
and FFmpeg are used to build and test but are not part of the release files. FFmpeg's `testsrc2` and
